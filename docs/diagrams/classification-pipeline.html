5 · Module layout

src/rex/ml/
├── provider.py              (existing) LLM client
├── vision.py                (existing) Gemini vision
└── classifier/              NEW — plug-and-play module
    ├── __init__.py
    ├── base.py              # Protocol: fit() / predict() / explain()
    ├── registry.py          # name → factory; YAML-driven swap
    ├── algorithms/
    │   ├── knn.py           # default, uses LanceDB ANN
    │   ├── bertopic.py      # discovery + auto-labels
    │   ├── setfit.py        # SOTA few-shot (Phase 2)
    │   ├── llm_zero_shot.py # cold-start
    │   ├── llm_few_shot.py  # warm-start with label examples
    │   └── ensemble.py      # weighted vote across algorithms
    ├── lifecycle/
    │   ├── train.py         # rebuild from corrections
    │   ├── eval.py          # F1 / accuracy / calibration metrics
    │   ├── drift_detector.py# sha256 / path / model-version drift
    │   └── snapshot.py      # versioned model artifacts
    └── config_schema.py     # per-domain profile (algo + hparams)

6 · Per-domain config example

# .raven/classifier_config.yaml
algorithms:
  default: ensemble
  ensemble:
    members: [knn, bertopic, llm_zero_shot]
    weights: [0.5, 0.3, 0.2]      # tuned from per-algo F1

per_domain:
  - match: "Marketing/*"
    classifier: setfit
    retrain_threshold: 50
    fallback: knn

  - match: "Code/*"
    classifier: knn
    k: 7
    embedding: code-bert          # swap embedder per domain

  - match: "Images/*"
    classifier: clip_zero_shot
    candidate_labels_from: business_context.domains

drift:
  schedule: "0 3 * * *"           # nightly 3am
  staleness_alarm_pct: 5
