Stage 2 LLM Router Agent (per file, intelligence)

Module: src/rex/agents/router.py  ·  Class: LLMRouter

StepActionFile / ModuleFunction
2.1 Idempotency: decision already exists?
  • If yes → skip LLM call, reuse decision
 src/rex/orchestrator/state.py JobStore.get_decision()
2.2 Deterministic dedup check first
  • Look at top neighbor's cosine similarity
  • ≥ 0.9999 → EXACT_DUPLICATE → action = TRASH
  • ≥ 0.92 → NEAR_DUPLICATE → action = ARCHIVE
  • ≥ 0.80 → RELATED → flag only
 src/rex/agents/router.py LLMRouter._check_dedup()
2.3 Build structured prompt for LLM
  • Filename + extension + media_type + size + modified
  • Extracted text (first 1500 chars)
  • Image description (if any)
  • Top-3 similar neighbors with similarity scores
  • Existing categories list
 src/rex/agents/router.py build_user_prompt()
2.4 LLM call with 3-retry backoff
  • Calls ModelProvider.generate() with JSON mode
  • Routes to Ollama / Bedrock / Gemini based on REX_LLM_PROVIDER
  • Local default: qwen3:8b via Ollama
 src/rex/agents/router.py LLMRouter._classify_with_retry()
2.5Parse model output (strips markdown fences, regex-finds JSON)src/rex/agents/router.pyextract_json()
2.6 Validate against FileDecision schema
  • category, tags[], relevance 1-5, action, reasoning
  • Pydantic raises on invalid → retry
 src/rex/models/schemas.py FileDecision
2.7Normalize fields (sanitize category, lowercase tags)src/rex/agents/router.pyLLMRouter._build_decision()
2.8 Overlay dedup result on LLM decision
  • Dedup wins: TRASH for exact, ARCHIVE for near-dup
 src/rex/agents/router.py LLMRouter.route()
2.9 Fallback if all retries fail
  • Heuristic category from extension
  • Mark unclassified tag, relevance=3
 src/rex/agents/router.py LLMRouter._fallback_decision()
2.10Persist FileDecision to JSONsrc/rex/orchestrator/state.pyJobStore.save_decision()
2.11Brief sleep (50ms) to keep Ollama happysrc/rex/orchestrator/pipeline.pyasyncio.sleep(0.05)

Parallel Processing — Today vs Future

Today Sequential per file

  • Files are scanned one at a time (limited by LocalFSPlugin)
  • Routing is sequential (one LLM call at a time)
  • Organizing is sequential (one copy at a time)

Already plumbed — just needs flipping on

Parallel JobWhereTrigger
Concurrent Ollama LLM callssrc/rex/ml/provider.py embed_batch()Already supports REX_OLLAMA_PARALLEL=N
Concurrent embeddingssrc/rex/ml/provider.py embed_batch()Same env var
Concurrent scanning + extractionNeeds asyncio.gather() in RexPipeline.run()Easy refactor
Concurrent vision callssrc/rex/ml/vision.pyOne Gemini call per image — naturally batch-able

Future Prefect-based parallelism

  • Each file is a Prefect task → all 500 files fan out across N workers
  • Retry policies per file
  • Resume from any failed task
  • Observability dashboard
